# Media Asset Clearance

Media clearance verifies that every image, font, audio, and video asset in a deliverable is covered by a license appropriate to its actual use. Stock licenses, font EULAs, and model/property releases each carry distinct terms, and embedded metadata is the primary evidence chain. The advisor flags assets whose license does not match their use.

## Watch for
- Images reverse-searched from the web with no license record ("found on Google").
- Stock licenses used beyond their terms: editorial-only in advertising, print-run caps exceeded, or resale in templates.
- Fonts embedded in apps, games, or documents without an embedding/app license.
- Music tracks used in video without sync rights, or royalty-free claims from unverified sources.
- Identifiable people or private property without model/property releases in commercial use.
- Stripped metadata (EXIF/IPTC) that destroys the attribution and license evidence chain.
- AI-generated media with unclear platform terms on commercial use and output ownership.
- One license record covering a whole asset folder rather than per-asset verification.

## Best practices
- Require a per-asset license record: source, license type, scope, date, and purchaser.
- Match license scope to actual use: medium, territory, duration, run count, and resale.
- Verify model and property releases for identifiable people or private property in commercial contexts.
- Check font EULAs for embedding, webfont, and app-use grants separately from desktop use.
- Preserve embedded metadata through the asset pipeline; store originals.
- Buy music with the rights actually needed (sync, master) from verifiable libraries.
- Record the AI-generation tool and platform terms for any generated media.
- Keep an asset clearance register reviewed before each release.

## Quick checklist
- [ ] Every asset has a per-asset license record
- [ ] License scope matches actual use
- [ ] Model/property releases on file where needed
- [ ] Font EULA covers embedding and distribution
- [ ] Music rights (sync/master) verified
- [ ] Metadata preserved in the pipeline
- [ ] AI media terms documented
- [ ] Clearance register reviewed pre-release
