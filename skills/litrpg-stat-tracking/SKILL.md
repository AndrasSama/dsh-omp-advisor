# LitRPG Stat Tracking

LitRPG readers treat stat blocks as load-bearing canon: a strength score, an XP total, a skill rank must be arithmetically consistent chapter to chapter.
Number errors are among the most-reported issues in the genre, and inconsistent progression math quietly breaks the power curve the story is built on.

## Watch for
- Arithmetic errors in stat blocks: points spent that don't match new totals, or unspent points that vanish
- XP/level inconsistencies: level-ups at the wrong threshold, or thresholds that shift without a system change
- Skill ranks advancing without the stated conditions (usage count, quest, trainer) being met
- Stats used inconsistently: a character with 12 Strength lifting what 20 Strength failed earlier
- Interface boxes contradicting narration (box says Poisoned; narration ignores it for ten pages)
- Party XP splits or shared-kill rules applied inconsistently between fights
- New skills or classes appearing with no unlock trigger, or unlocked options silently forgotten

## Best practices
- Maintain a living character sheet: current level, XP toward next, all stats, spent/unspent points, skills with ranks and unlock chapters
- Define the progression formula once (XP per level, points per level, rank thresholds) and never bend it without an in-world event
- Recalculate totals on every stat block before publishing; show the math in the sheet, not just the result
- When stats matter in a scene, cite the number in narration so readers can verify the feat
- Keep interface boxes visually consistent (same bracket/box style) and treat their contents as binding canon
- Announce rule changes (system updates, class evolutions) explicitly before they affect the math
- Audit every 10 chapters: re-derive current totals from the formula and compare against the last printed block

## Quick checklist
- [ ] Do all stat blocks add up: previous total ± spent points = printed total?
- [ ] Does any level-up match the established XP threshold?
- [ ] Are skill rank-ups backed by their stated unlock conditions?
- [ ] Do feats in narration match the numbers in the most recent stat block?
- [ ] Are interface statuses (buffs, debuffs) reflected in the following scenes?
- [ ] Are party/XP split rules applied the same way as in previous chapters?
- [ ] Is the character sheet updated to match this chapter's printed block?
