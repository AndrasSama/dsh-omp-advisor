# Macroeconomic Indicator Tracking

Macro tracking grounds financial analysis in official indicators — inflation, rates, employment, activity. Review focuses on data hygiene: source agency, vintage, seasonal adjustment, and growth-rate conventions. Misread indicators (advance vs revised, MoM vs annualized) silently corrupt every conclusion built on them.

## Watch for
- Indicators cited without release date, vintage, or source agency (BLS, BEA, Federal Reserve, Census, ISM).
- Advance or preliminary estimates used where revised/final figures exist (e.g., advance GDP vs the third estimate).
- Seasonally adjusted and non-seasonally-adjusted series compared against each other.
- Initial prints relied on after material revisions changed the picture.
- Conflated growth conventions: US GDP is reported QoQ annualized; CPI is typically cited YoY — mixing them misstates momentum.
- Leading/lagging misclassification (e.g., treating unemployment as a leading indicator).
- National indicators applied to a company or portfolio with different geographic exposure.
- Stale data: a newer release exists but the analysis uses last period's print.

## Best practices
- Record series name, source agency, vintage/release date, seasonal-adjustment status, and units for every indicator.
- Prefer the latest revised figure; explicitly note when analysis must rely on an advance estimate.
- Standardize and state growth-rate conventions (YoY vs QoQ annualized) before comparing series.
- Track the release calendar (FOMC meetings, CPI, NFP, GDP) so analyses always use the newest vintage.
- Classify indicators as leading, coincident, or lagging and use them accordingly.
- Match indicator geography to the exposure analyzed; note regional divergences explicitly.
- Note benchmark revisions (NFP annual benchmark, CPI reweighting) that change historical interpretation.
- Distinguish market expectations from actual prints; surprises, not levels, typically move markets.

## Quick checklist
- [ ] Source agency and release date recorded per indicator.
- [ ] Advance vs revised status noted.
- [ ] Seasonal-adjustment status consistent across series.
- [ ] Growth-rate convention stated for each figure.
- [ ] Leading/lagging classification correct.
- [ ] Geography matches the exposure analyzed.
- [ ] Latest available vintage used.
